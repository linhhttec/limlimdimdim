# limdim.softie (website)

Đưa lên Netlify: kéo thả cả thư mục này vào Netlify Drop, hoặc đẩy lên GitHub rồi Import (Build command để trống, Publish directory là `.`).

Dữ liệu sản phẩm và danh mục nằm trong `content/products.json` và `content/categories.json`. Sửa hai file này rồi deploy lại là web cập nhật.

Khi chạy thử trên máy, mở bằng máy chủ cục bộ (ví dụ `npx serve .`), không bấm đúp `index.html`.
